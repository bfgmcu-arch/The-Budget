# Download tracking

GitHub counts downloads for files attached to releases. These badges show the total downloads across all releases and the downloads for the latest release:

[![Total release downloads](https://img.shields.io/github/downloads/bfgmcu-arch/The-Budget/total?label=release%20downloads)](https://github.com/bfgmcu-arch/The-Budget/releases)
[![Latest release downloads](https://img.shields.io/github/downloads/bfgmcu-arch/The-Budget/latest/total?label=latest%20release)](https://github.com/bfgmcu-arch/The-Budget/releases/latest)

## What is counted

These badges report downloads of assets attached to published GitHub Releases. GitHub does not count repository clones or downloads of the automatically generated “Source code (zip)” and “Source code (tar.gz)” archives as release-asset downloads. To track app downloads, attach the installer or other distributable files as assets to each published release. Counts update as GitHub records asset downloads.
